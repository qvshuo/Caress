# 架构契约

## 项目职责与数据流

Emby 所选库分页读取 → 根据媒体文件名识别番号与媒体属性 → 检查补齐需求 → 按来源顺序精确命中 → 演员映射、翻译和图片加工 → 按 Item 写入 Emby → 回读验证 → 记录结果。

Emby 管理媒体、元数据、人物和图片。Caress 不挂载媒体目录，不写 NFO，不保存完整元数据或原始数据历史。详情定向校验所选库范围后实时读取；离线明确报错，不展示旧数据。模块职责见 AGENTS.md。

## 番号与来源

仅剥离文件名末尾的 `-C`、`-U`、`-UC`、`-cdN`。字幕、无码破解和分集属性用于展示及文件名标签，不决定作品发行分类。

FC2PPV 为 FC2，日期式纯数字番号为无码。其他番号按完整前缀精确查询 `data/catalog_rules.json` 的有码、无码白名单，保留复合前缀和数字命名空间，剥离末尾多段数字以提取前缀，不按字符串包含关系或普通番号形态推断。有冲突或未收录的前缀保持 UNKNOWN，四类来源配置分别生效。

来源返回空白标题时在加工前报错，不进入 Emby 写入。

静态表依据经过核验的 JavDB 有码和 AVSOX 无码公开作品记录手动生成；分类仅决定查询优先级，不证明作品身份。运行时只加载本地 JSON，不查询 JavDB App API、不动态学习或自动更新。精确规范化、来源身份核对和 DMM CID 验证独立于前缀分类。

来源按配置优先级查询，首次命中即停，不借用其他来源字段。UNKNOWN 默认优先综合来源；已保存的用户顺序不自动调整。DMM 先构造 CID，无结果时搜索官方候选，再获取官方数据；CID 必须保留请求番号的完整前缀和数字身份，不猜测额外数字命名空间。

Scrapling 处理网页，httpx 处理 API 和图片，FlareSolverr 处理需要挑战验证的页面。来源独占、限速、冷却及有限网络重试独立于作品并发。来源处理时限与锁等待分别限制，排队超时不报告为请求超时。

番号规范化只统一已确认的拼写（含 FC2 别名）；查询转换仅服务于搜索请求。身份比较严格保留数字番号的下划线与连字符差异。来源适配器只能根据明确的命名空间证据还原完整番号，由 Scraper 统一比较请求与最终来源番号；候选筛选及详情页/作品 ID 的来源证据核对保留在适配器内。离线采集复用同一来源编号恢复函数。AVSOX 普通搜索直接复用严格匹配的完整搜索记录（作品 ID、编号和 `from`），随后与详情网页交叉验证；指定 ID/URL 时才请求详情 JSON 核对身份，不额外搜索。

## 演员与翻译

Gfriends Filetree 是演员别名、标准名称和头像地址的唯一数据源。映射使用 NFKC、空白规范化与 casefold；实际图片文件名去除 `AI-Fix-` 和末尾图片编号后作为标准名称，最后一个来源优先。未命中保留来源原名，多个艺名命中同一名称时合并。

索引只保留在当前加工实例内，不写 SQLite。索引不可用时保留原名并警告，不阻断作品刮削；头像失败不回退标准名称。

翻译只处理标题和简介，保护来源原名及标准演员名；失败保留有效原文。标题按番号和标准演员名组装。原始标题使用 Emby `OriginalTitle`，翻译标题使用 `Name`，简介使用 `Overview`，不增加原始数据快照。

## Emby 元数据写入

写前复核服务器、Item 身份和所选库归属，读取完整 DTO 后有限合并，不改变非受管属性、LockData 或 LockedFields。只修改 `caress` ProviderId，其他 ProviderIds 保留。元数据和图片写后均回读验证，HTTP 成功不代表持久化。

- **刮削缺少的元数据（scrape）**：保留已有有效字段及 Actor/Director 名单，只补缺失内容。标题与文件名主干或规范番号完全相同时视作占位标题。标签只补空集合及文件名标识；已有 Primary 不覆盖。
- **重建元数据（force）**：确认后以本次成功来源结果重建。有效标题替换；原始标题、简介、年份、发行日期、制作商、类型及 Actor/Director 在缺失时清空，标签按本次来源和文件名属性重新建立。其他人物和非受管属性保留，同名人物复用原对象。新封面准备成功后替换 Primary，整个 Backdrop 集合重建，演员头像重新获取并替换。

来源失败不会先清空 Emby。Emby 没有跨请求事务，部分写入失败必须如实标记并允许重试。最近失败的作品绕过补齐预检查；其他作品依据 Emby 当前内容判断是否需要加工。只有确认没有变更时才跳过并恢复原处理记录。图片写入请求发出后验证失败，保留本轮处理结果及警告，不恢复旧记录；警告不表示图片已验证成功。

头像在元数据写入前按需准备，写入后使用 Emby 回读的 Person ID 关联。补齐保留已有头像，重建替换已匹配且准备成功的头像；未匹配或失败保留原图并警告。下载在批次临时目录复用，人物锁避免重复上传，下载与上传均最多两次尝试。

## 图片获取与裁剪

图片限制为 32 MiB、40MP，Pillow 解码验证并处理必要的 EXIF 方向。背景图只使用实际横向封面或剧照，不能用竖版 Primary 代替。同 URL 原图仅抓取一次，同番号按需复用一次裁剪结果。

补齐按像素内容去重追加 Backdrop。重建将整个 Backdrop 集合作为受管范围，包括原有自定义背景；新图全部验证、上传并回读成功后，逆序删除旧图。本次没有有效候选时清空集合；来源剧照列表未完整取得或图片准备失败则不替换，上传失败保留旧图并警告。已上传的新图可能部分保留，删除失败也如实告警，不模拟事务或回滚。其他图片类型不变。

已有图片逐张读取，RGBA 条带摘要限制内存峰值；摘要仅活在当前加工结果内，不持久化。保留像素比较以支持编码不同的相同图片及上传回读验证。

图片在写入前准备，慢速准备后再复核 Item 身份与所选库归属。重建没有封面候选时保留原有 Primary 并提示；需要写入的 Primary 准备失败则阻止写入。背景和头像失败保留警告。Emby 明确拒绝的图片请求不计入变更；请求结果不明或写后回读失败时保留可能部分写入的结果。下次手动操作可以重新尝试。

手动裁剪优先使用 Emby 横向背景，支持从来源获取完整封面，失败保留原会话和选框。新原图及首次预览成功后才替换唯一活动会话，旧响应不得覆盖新图。固定 2:3，无拉伸；YuNet 按需加载并缩图检测。最终 PNG 只上传 Primary，不改变背景、人物或处理记录。保存成功后的详情刷新独立结算。

裁剪会话十分钟惰性过期，关闭、保存或配置变化时清理，无后台定时器。批次临时文件在结束后释放。

## 批次执行

连续批次使用开始时的全局配置快照，包括 Emby 连接与翻译设置。运行中追加请求只保留自己的模式和来源，新设置在下一批生效；队列按提交顺序执行；每次提交内部默认四并发，同番号共享一次刮削、翻译和加工，每个 Item 独立验证和写入。同 Item、模式、来源的未完成请求去重，同 Item 写入互斥。

开始时读取所选库 Movie ID 集合，关联 Video 或新 Item 单独验证范围；展开关联逐项去重，无法确认项单独跳过。慢速加工结束后再次复核身份和归属。最后一个使用者取消并等待未完成的共享加工，释放临时文件。

取消停止未开始的处理和全部等待项；已开始写入的操作完成后回读并如实结算，保留已完成结果，不声称外部回滚。重启标记中断，不自动续写，不建立历史任务中心。

## SQLite 与生命周期

| 表 | 内容 |
| --- | --- |
| options | 当前设置，密钥仅在服务端 |
| scrapes | 服务器及 Item 身份、历史成功、最近结果与原因、成功来源 |
| batch | 唯一当前/最近批次、各项进度、写入边界与失败原因 |
| cooldowns | 来源及请求主机冷却 |

事务保护写入。成功历史与最近结果独立，缺席 Emby 的 Item 不触发破坏性删除。不提供配置历史、数据库导入或迁移框架。

Service 持有 Emby 连接池，请求和批次租用；配置变化切换新池，活动租用结束才关闭旧池。关闭服务先取消批次，再关闭连接与 SQLite。Compose 使用命名卷，Caress 以非 root 运行，数据位于 `/data`，FlareSolverr 配置位于 `/config`。

## 前端交互

列表和详情共享批次进度，运行中的结果覆盖当前 Item 状态和对应错误；批次结束后以实时 Emby 投影为准。处理中和成功不显示旧失败提示。当前详情处理结束后重新读取，批次结束刷新列表；轮询不重复读取全库。连续三次轮询失败提示，恢复后清除。

首次加载、页面恢复可见、窗口焦点、主动刷新及运行中轮询共用批次同步入口；发现运行中任务才轮询，空闲不持续请求。同步只复用有效代际的请求，旧响应不得覆盖新操作。

搜索保留 200ms 输入延迟、请求取消和旧响应保护。版本列只显示文件名表达的字幕、无码破解和分集属性，普通文件留空，不统计 MediaSource 数量。详情固定结构化字段缺失时使用弱化的 `—`，人物保留头像卡片，空背景图不显示占位区。列表导航、分页、系统主题和键盘交互沿用现有组件。列表按不支持、失败、已处理、待处理排序，同组按番号升序，筛选与导航共用该顺序。

设置仅提供 Emby、翻译和四类来源顺序；输入变化或离开页面使旧连接响应失效。来源地址内置，非法顺序直接拒绝。

图片代理限定可信 Emby 地址、合法 Item、Primary/Backdrop 和有限索引；Person Primary 必须由所选库 Movie 的 People 关联确认。密钥使用请求头，不返回前端或写日志。固定界面文案为中文，内部日志为英文，上游 JSON 错误保留原始内容。用户自行关闭 Emby 在线提供者；扫描、刷新与重新入库遵循 Emby 自身语义。

## 开发与测试

检查命令和仓库外环境隔离要求见 AGENTS.md。CI 保留 Python 与前端两个 Job；交付前验证 Compose 构建、启动、健康检查和重启。真实写入只针对明确隔离的测试 Item；未执行的真实服务验证须如实说明，不以 Mock 代替。


测试按职责维护：`test_modes.py` 与工作流中的写入、批次、取消用例守住业务契约，人物和图片测试覆盖对应加工边界；`test_sources.py` 及文件名用例验证来源、分类和身份边界；Playwright 验证列表、详情、设置、批次、图片与裁剪交互。名单使用少量代表性测试，不逐前缀建用例。Python 使用 pytest，`tests/web/` 使用 Playwright，保持独立运行器。手动采集脚本不进入正式请求或批次生命周期。
